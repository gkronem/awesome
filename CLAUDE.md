# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What This Is

A meta-list: a curated list of awesome lists, maintained in `readme.md`. There is no build system or code — the entire repo is Markdown.

## Contribution Rules

From `pull_request_template.md` and `contributing.md`:

- PRs add a single awesome list. Title format: `Add Name of List` (no "Awesome" in title, title-cased).
- Entry format: `- [List Name](url#readme) - One-sentence description of the topic (not the list). Ends with a period.`
- Entries go at the bottom of the appropriate category in `readme.md`.
- The submitted list must: have an `awesome-list` GitHub topic tag, an awesome badge linking back here, a Table of Contents named `Contents`, a `contributing.md`, an appropriate CC license, and have existed for at least 30 days.
- No blockchain-related lists. No AI-generated lists.
- Description must describe the topic/project, not the list itself. First character uppercase.
